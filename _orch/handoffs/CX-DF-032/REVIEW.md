## Blocking Findings

### Critical 1 — Evidence has no valid link to its observation

Final `metric_evidence.json` rows contain neither `observation_id` nor a logical observation-key reference. The approved table requires `observation_id BIGINT NOT NULL`.

The dry-run adapter attempts:

```js
getObservationId(e.observation_key || e.evidence_key.replace("ev:", "obs:"))
```

But final evidence rows have no `observation_key`, and replacing the evidence-key prefix does not reconstruct the canonical observation key. Evidence therefore receives IDs unrelated to the actual observation IDs.

Required correction:

- preserve a deterministic logical `observation_key_ref` in a separate evidence-plan artifact or pre-materialization plan;
- create a pure materializer that accepts the database-assigned `Map<observation_key, observation_id>` and `Map<ingestion_plan_key, run_id>`;
- emit final schema evidence only after replacing logical references with real IDs;
- dry-run adapter must use the same materializer with deterministic numeric IDs;
- assert every observation has exactly one matching evidence row and every evidence row resolves to an existing observation.

### Critical 2 — “Double run” test does not run the parser twice

`runParser()` is a stub returning `{ok:true}` and is unused. The test compares `artifacts/` with the copied handoff directory generated by the same parser invocation. This is a copy comparison, not a double-run determinism test.

Required correction:

- export/invoke the parser with an explicit output directory, or execute it twice as a subprocess;
- generate into two fresh temporary directories;
- compare SHA-256 for each canonical logical artifact;
- clean temporary directories after the test.

### High 1 — Ingestion/source adapter assigns House evidence to Unit run

The adapter determines property type using:

```js
e.metadata.sheet === "Table 1" ? "unit" : "house"
```

Both workbooks use sheet `Table 1`, so House evidence is assigned to Unit run ID 2. Because both runs share the same source key, the current source-consistency validator cannot detect this workbook-level mismatch.

Required correction:

- store a deterministic ingestion-plan reference in the logical evidence plan;
- map house checksum to house run and unit checksum to unit run;
- assert exactly 749 evidence rows map to house and 384 to unit;
- add a negative wrong-run fixture.
