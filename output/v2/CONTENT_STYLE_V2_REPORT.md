# Content Style V2 Report

**Date:** 2026-06-11  
**Objective:** Transform research-report content into native social media content.

---

## 1. Core Rules (V2)

### Rule 1: Hook-first, not label-first
- **V1:** "2026 维州增长最快的 10 个郊区"
- **V2:** "Deer Park 一年涨了 30%，你猜现在入手要多少钱？"

### Rule 2: Lead with real data, not scores
- **V1:** "NO.1 Deer Park — 机会分 36"
- **V2:** "中位价 $730,000，一年涨 30%。为什么还能涨？"

### Rule 3: Conversational Chinese
- **V1:** "我们的 9 维评分系统给它打了高分"
- **V2:** "你打开地图，Deer Park 在墨尔本西边——以前没人看的地方，现在成了涨幅第一。"

### Rule 4: Include investor questions
- **V1:** 陈述事实，没有互动
- **V2:** 每段结尾抛一个"你来判断"的问题

### Rule 5: Three versions per topic
- Research → data-heavy, skeptic audience
- Xiaohongshu → consumer psychology, FOMO, lifestyle
- Short video → hooks, speed, CTA

## 2. Template Architecture (V2)

### Research Version
```
Hook (data insight, not title)
│
├─ The Data (brief, high-signal)
│   ├─ Key metric #1 → source
│   ├─ Key metric #2 → source
│   └─ Why this matters
│
├─ The Skeptic Question (what a smart reader would ask)
│   ├─ "But is it too late?"
│   ├─ "Are there risks?"
│   └─ Honest answer
│
├─ Context (why this happened)
│
└─ Call to action (what to do next)
```

### Xiaohongshu Version
```
Headline (hook → pause → payoff)
│
├─ Body: one premise, two data points, one "you decide"
│
├─ Format rules:
│   ├─ NO titled sections (no "深度分析：" labels)
│   ├─ Short paragraphs, max 2-3 lines
│   ├─ One emoji per paragraph max
│   └─ Reader addressed directly (你/你的)
│
└─ Hashtags: 4-6, mix of high-volume and niche
```

### Video Version
```
0-3s:   Hook (surprising number or question)
3-8s:   The reveal (specific suburb, specific number)
8-15s:  Context (why — one clear reason)
15-20s: Gut check (audience question)
20-25s: The nuance (honest risk note)
25-30s: CTA (clear, low-friction)
```

## 3. V2 Demo: top-growth

### Research Version

Deer Park 一年涨了 30%，现在中位价才 $730,000。

这不是瞎猜的。数据来源是 realestate.com.au 的真实成交记录加上 ABS 人口普查的底层结构数据。

三个数据点：
1. 一年涨 30%，三年涨了 25%。这不是偶然爆发——是连续稳定的上涨。
2. 空置率只有 2.44%。100 套房子只有 2 套空着。这说明什么？需求在，供应跟不上。
3. 中位价 $730,000。在墨尔本增长最快的郊区里，这是价格洼地。

一个理性的问题：这个时候进场，会不会追高？

我们看一个指标：价格收入比（PIR）。维州平均值是 8-9 倍年收入。Deer Park 的数据没有超过这个范围。意思是，这里的涨幅不是泡沫吹出来的，是实际购买力支撑的。

另一个角度：学区评分 40.2/100。不高。但这恰恰说明它的增长不是靠学区溢价——是真实的人口流入和基建驱动。

投资者会问的问题：
- Rockbank 中位价更低（$583,000），但空置率更高（5.43%）。你愿意用更低的租金保障换更低的总价吗？
- Clyde North 学区评分高（56.2），中位价 $770,000。同样的涨幅，不同的安全垫——学区的溢价是长期还是短期？

数据不能替你决策。但它能帮你把决策从「感觉」变成「判断」。

## 4. Key Differences: V1 vs V2

| Dimension | V1 | V2 |
|-----------|----|----|
| First sentence | "2026 维州增长最快的 10 个郊区" | "Deer Park 一年涨了 30%" |
| Score displayed | "机会分 36" upfront | Score omitted or buried in context |
| Reader address | No direct address | "你" / "你的" / "你会选哪个？" |
| Research depth | "我们的模型有信心" | "三个数据点… 一个理性的问题…" |
| Questions | None | Model questions from buyer perspective |
| Depth analysis | Labeled section "💡 深度分析：" | Integrated into narrative, no label |
| Hashtag relevance | Generic (#澳洲房产 #增长最快) | Specific (#DeerPark #买房攻略) |
| Risk note | Generic disclaimer | Specific: "学区溢价 vs 增长驱动" |
| Video hook | Reads the title | Surprising number + mystery |

## 5. Implementation

The V2 style is designed for the social content engine's template system.

To integrate:

1. **Research version** uses the `renderResearch` template — data-first, skeptic-aware
2. **Xiaohongshu version** uses the `renderXiaohongshuV2` template — hook-first, FOMO-aware
3. **Video version** uses the `renderVideoV2` template — speed, rhythm, questions

Templates are data-driven: they fetch the same API data but arrange it differently.

➡ Templates can be added to `scripts/generate-content.mjs` as new render functions.
➡ CLI flag `--v2` could switch between V1 and V2 output styles.

## 6. Risks & Open Questions

- **API data quality**: All 10 suburbs share the same growth1y/growth3y values. This limits differentiation in content. Rich data → rich content.
- **Video production gap**: Scripts are written for human editors. V3 should automate screenshot capture + TTS voiceover.
- **Tone tuning**: Xiaohongshu tone varies by author. The V2 template assumes a "data-savvy investor" persona. A younger persona would need shorter sentences, more emoji, stronger emotion.
