## 使用说明

1. 复制任意 Prompt 到 DALL·E / Midjourney / GPT-Image
2. 替换 `[SUBURB]`, `[PRICE]`, `[GROWTH]` 等占位符
3. 尺寸：视频用 1080×1920，小红书用 1080×1440
4. 生成后存入 `assets/generated/{topic}/`
5. 一个场景如果不太满意可以多跑几次选效果最好的
